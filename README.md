# Shelly_BLE_scripts

# switchbot_temp.js
converts switchbot sensor data (temperatur/humility sensor) to BTHome V2 MQTT messsages for iobroker Shelly adapter
Tested with Switchbot Meter Plus, Shelly Plus i4, Shelly1 Mini Gen3 and iobroker shelly adapter 10.4.0
Sources partly derived from:
- https://github.com/Vanuan/switchbot-meter-to-shelly
- https://github.com/iobroker-community-adapters/ioBroker.shelly
